# Bhuvan Veeravalli — Portfolio

Personal portfolio website of **Bhuvan Veeravalli**, Computer Science student at the University of Alberta specializing in backend development and machine learning.

**Live site:** [bhuvanveeravalli.com](https://www.bhuvanveeravalli.com)

## What's Inside

- **About** — background, research work at the Renewable Thermal Energy Lab, and NSERC Undergraduate Student Research Award
- **Skills** — backend systems, databases, cloud/DevOps, and AI/ML tooling
- **Experience** — research and teaching assistant roles at the University of Alberta, plus certifications
- **Projects** — selected work including IntelliDocs (RAG document intelligence), SocialDistribution (federated social network), FlightPredict (ML delay prediction), and more
- **Contact** — email, LinkedIn, and GitHub links

## Tech Stack

- [React 18](https://react.dev) + [TypeScript](https://www.typescriptlang.org)
- [Vite](https://vitejs.dev) for build tooling
- [Tailwind CSS](https://tailwindcss.com) for styling
- [shadcn/ui](https://ui.shadcn.com) component library

## Development

```sh
npm install       # install dependencies
npm run dev       # start dev server
npm run build     # production build
npm run preview   # preview the production build
npm run lint      # run ESLint
```

## Structure

```
src/
├── components/     # page sections (Hero, About, Skills, Experience, Projects, Contact)
│   └── ui/         # shadcn/ui primitives
├── pages/          # routes (Index, NotFound)
└── assets/         # images
public/             # static files (resume PDF, favicon, og image)
```
